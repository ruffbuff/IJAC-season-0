# IJAC — It's Just a Cube

Season 0, локальный прогон. Godot 4.2+.

## Запуск
1. Godot -> Import -> `game/project.godot`.
2. F5. Игра открывается сразу в полноэкранном режиме.

## Управление
| Клавиша | Действие |
|---|---|
| ЛКМ / ПКМ + мышь, стрелки | вращать камеру вокруг куба |
| Колесо мыши | зум |
| H | показать / скрыть панель истории |
| F11 | полный экран <-> окно |
| Esc | выход |
| WASD, Пробел | только в версиях, где это добавлено (v001 — движение, v002 — прыжок) |

## Панель истории
- **ACTUAL** — открывает текущую утверждённую версию (`current` в `game/data/versions.json`).
- **TIMELINE** — все версии; клик открывает любую. Новые сверху.
- Версии с пометкой `[demo]` — **симуляция** для проверки процесса, а не настоящие PR сообщества.

## Как устроены версии
- `game/scenes/Main.tscn` — оболочка (панель + контейнер World). Не меняется от версии к версии.
- `game/scenes/versions/vNNN.tscn` — каждая версия отдельным файлом-снимком. Старые не правим.
- `game/scripts/versions/vNNN/` — скрипты конкретной версии.
- `game/data/versions.json` — список версий и указатель `current`.

Добавить новую версию: скопировать последнюю сцену в `vNNN.tscn`, внести изменения, добавить запись в `versions.json`, поменять `current`.

## Экспорт (Windows)
1. Editor -> Manage Export Templates -> Download and Install.
2. Project -> Export -> «Windows Desktop» (пресет уже настроен) -> Export Project.
3. Результат: `builds/ijac-dev/ijac.exe` (один файл, `builds/` в .gitignore).

Сейчас это «dev-клиент»: оболочка со всеми версиями внутри одного exe. Отдельные неизменяемые сборки каждого релиза (`s0-v000`, ...) — следующий этап по плану Season 0.

## Git
Репозиторий создаётся вручную. Рекомендуемый корень — папка `ijac/` (рядом `game/`, `.gitignore`, `README.md`). Папки `.godot/` и `builds/` в репозиторий не попадают.
