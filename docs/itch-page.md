## Page description (paste into the editor)

**It's Just a Cube.** Today, it's nothing. Tomorrow, it's whatever we make it.

IJAC is an experiment in community-driven game development. Every season starts with one gray cube in an empty scene — no genre, no roadmap. Ideas become changes, changes get tested and voted on, and the game evolves. When a season ends, we archive it and start again with just a cube.

**This is Season 0: a technical prototype.** It is not a finished game. It tests the process, not the gameplay.

### What you can do in this build
- Orbit around the cube (mouse drag / arrow keys, wheel to zoom).
- Open the **history panel** on the left: press **ACTUAL** to see the current version, or pick any earlier one from **TIMELINE**.
- Try the three versions: Just a Cube, Movement (WASD), Jump (Space).

*Movement and Jump are demo versions written by the author to test the loop — not community contributions.*

### Controls
Mouse drag / arrows — camera · Wheel — zoom · H — hide/show history · F11 — fullscreen · WASD / Space — move / jump (v001, v002) · Esc — quit

### Install
Download the zip, extract, run `ijac.exe`. Windows may show a SmartScreen warning because the build is not code-signed: click **More info → Run anyway**.

### What's next
Contribution rules, a small closed test with real contributors and votes, then a public Season 1. Follow the project and join the discussion in the comments.
