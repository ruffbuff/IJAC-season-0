## Season 0 — baseline

First public snapshot of IJAC: a local technical prototype of the "cube → versions → history" loop.

**Included**
- Textured start cube on an endless grid, orbit camera (mouse / arrow keys / wheel).
- In-game history panel: **ACTUAL** + **TIMELINE**, switch between builds on the fly.
- Versions: `s0-v000` Just a Cube, `s0-v001` Movement (demo), `s0-v002` Jump (demo).
- Starts in fullscreen; F11 toggles, Esc quits.

**Notes**
- `v001` and `v002` are *simulated* proposals by the author, not community contributions.
- No contribution pipeline or voting yet.
- Windows build is unsigned: SmartScreen → *More info → Run anyway*.

**Asset:** `IJAC-s0-baseline-windows.zip` (contains `ijac.exe` and `LICENSE`).
